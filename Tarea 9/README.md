Programa desarrollado en C# que utiliza:

-Cadena de conexión a la base de datos mediante SqlConnection.
-Creación de la base de datos GastosDB en (localdb)\MSSQLLocalDB.
-Creación de tablas para almacenar los gastos.
-Consultas SQL para recuperar información.
-Tipos de datos INT, NVARCHAR y DECIMAL.
-Clave principal (PRIMARY KEY) para identificar cada gasto.
-Inserción de registros mediante INSERT INTO.
-Eliminación de registros mediante DELETE FROM.
-Uso de SqlConnection para establecer la conexión con SQL Server.
-Uso de SqlCommand para ejecutar comandos SQL.

Cómo ejecutar
- Abrir el proyecto en Visual Studio Community.
- Presionar F5.
